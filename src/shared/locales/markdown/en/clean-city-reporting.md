## Three reporting sources

1. **Volunteer portal** — [portal.russian.rs](https://portal.russian.rs/). One report per week, with every task of that week.
2. **Ekomapa** — [ekomapa.rs](https://ekomapa.rs/). Mark the cleanup (point or route, before/after photos, litres), then copy that data into the portal report. Sign in through the volunteer portal.
3. **Cloud** — [files.russian.rs](https://files.russian.rs/). Same login as the portal. Only for non-standard tasks. Ordinary cleanups no longer need cloud folders.

**Current rule.** Photos live on Ekomapa. The portal report gets the text copied from the map point. Do not attach cleanup photos on the portal.

**Deadline.** Last week’s report is due Monday. Ekomapa review takes up to 24 hours; portal review up to 7 days. A portal report is not accepted without an approved Ekomapa point.

## Mark a cleanup on Ekomapa

1. Open [ekomapa.rs](https://ekomapa.rs/) → **Sign in** → **Sign in via volunteer portal**.
2. Click the place on the map. Choose a **point** or a **route**.
3. Category: Clean City. Describe the waste. Upload **5 before photos**.
4. After the cleanup: **My points** → after photos, bag photos, litres → **Submit for moderation**.
5. Pair before/after shots from the same angle. Wait for the Ekomapa moderator.

---

## Submit the portal report

1. [Portal](https://portal.russian.rs/) → **New report**.
2. Copy the point data from Ekomapa.
3. Title = point code + place. Description = Ekomapa paste. Result = the same map link. Hours and date per location. No customer, no files.
4. Several cleanups = several tasks in one report.
5. **Submit** and wait for the portal moderator.

The activity heatmap lists only people with a current regular contract. Associated volunteers and expired contracts are not shown.
